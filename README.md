# Simple Test Game

A simple 2D platformer game created with Godot.

## Features
- Basic player movement (left/right arrow keys)
- Jump functionality (space bar)
- Simple ground collision

## How to Run
1. Install Godot Engine (version 4.0+)
2. Open the project in Godot
3. Press F5 to run the game

## Controls
- Left/Right Arrow Keys: Move left/right
- Space Bar: Jump

## Project Structure
- `project.godot`: Project configuration file
- `scenes/main.tscn`: Main game scene
- `scripts/player.gd`: Player movement script
- `assets/`: Directory for game assets
